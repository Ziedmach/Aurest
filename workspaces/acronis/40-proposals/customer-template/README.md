# <Customer name> — Acronis proposal folder

Copy this folder to `40-proposals/<customer-slug>/` for every opportunity.

| File | Purpose |
|---|---|
| `00-discovery.md` | Discovery notes: environment inventory (servers, VMs, workstations, M365 seats, data volumes, RPO/RTO), current tools, compliance drivers, decision process, budget signals |
| `10-sizing.md` | Workload counts and storage estimate mapped to Acronis SKUs; data center and residency choice; licensing model chosen (solution-based or service-based) and why |
| `20-proposal.md` | The proposal, built from `../proposal-template.md` |
| `30-pricing.md` | Buy-cost from `30-pricing/`, margin applied per the pricing policy, customer price in local currency with the USD reference rate and validity |
| `40-follow-up.md` | Objections, next steps, decision timeline, who said what |

Never commit customer personal data (names of individuals, emails, phone numbers) or
customer documents marked confidential. Keep those in the CRM or the shared drive and
reference them here by title only.
