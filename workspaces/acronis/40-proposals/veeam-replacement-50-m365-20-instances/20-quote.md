## Scope

Replacement of the current Veeam subscriptions (Veeam Data Cloud for Microsoft 365, 50
users, and Veeam Data Platform Advanced, 2 packs of 10 instances) with Acronis Cyber Protect
Cloud operated by Next Step Middle East.

| Current Veeam line | Acronis service proposed | Quantity |
|---|---|---|
| Data Cloud for Microsoft 365 Flex, 1 to 50 users, 1-year subscription, 24/7 support | Backup of Microsoft 365 seats with unlimited Acronis-hosted cloud storage included | 50 seats |
| Data Platform Advanced Universal Subscription, 2 × 10-instance packs, 1-year subscription, 24/7 support | Backup of virtual machines (agentless for VMware, Hyper-V, Nutanix, Proxmox; agent-based otherwise), backups to the client's existing storage included | 20 virtual machines |

What is included:

- **Microsoft 365 seats:** Exchange Online, OneDrive for Business, SharePoint Online and
  Microsoft Teams backed up several times a day, retention unlimited within the term,
  unlimited Acronis-hosted cloud storage included (subject to the Acronis fair-use policy),
  Acronis cloud data center in [Frankfurt, Germany] (European region, ISO 27001 certified).
- **Virtual machines:** image-level backup with application-aware processing (Active
  Directory, SQL Server, Exchange), instant and granular restore, immutable backups,
  ransomware protection on the backup agent, backups written to the client's existing
  backup storage (NAS, SAN, disk) at no extra charge.
- **Service:** migration from Veeam (policy mapping, agent and hypervisor connector
  deployment, first full backups, restore test), 24/7 monitoring by Next Step, service desk,
  monthly protection report, quarterly restore test with signed report.
- **Support:** Next Step service desk with escalation to Acronis partner support; priority-1
  incidents (failed restore of a production system) handled 24/7.
- Term: 12 months. Billing frequency per the option selected below.
