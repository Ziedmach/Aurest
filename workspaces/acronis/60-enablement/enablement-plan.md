## Demo and lab environment

- NFR tenant protecting Next Step's own estate (servers, laptops, Microsoft 365).
- Demo customer tenant with sample data: one Windows server, one Linux VM, three
  workstations, a Microsoft 365 test tenant, a DR recovery server. Scripts in
  `demo-scripts.md`.
- Simulated ransomware sample (EICAR-style and a safe encryption simulator) to show
  detection and rollback.
